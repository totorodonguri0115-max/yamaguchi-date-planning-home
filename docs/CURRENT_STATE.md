## 現在の作業目的

山口県デートプランホームを、単なるスポット一覧ではなく、以下を実現するページへ育てる。

- 彼女の好みに合うデート候補を選びやすくする
- 期間限定展示、祭り、花の見頃、企画展、地域行事、旬の食などの見落としを減らす
- デートのマンネリ化を防ぐ
- 季節、天気、時間帯、体力、屋内外、服装、予算感から選べるようにする
- 候補を彼女に相談しやすい形に整える
- デートの前後に使うご飯処を、エリア・距離・料理・時間・予算・気分から探せるようにする

## 現在の最重要方針

場所から先に選ぶのではなく、以下の順でデート候補を組み立てる。

1. 季節
2. 天気
3. 時間帯
4. ロングデート / ショートデート
5. 屋内 / 屋外
6. 服装・靴・持ち物
7. 予算感
8. 具体的な場所・イベント
