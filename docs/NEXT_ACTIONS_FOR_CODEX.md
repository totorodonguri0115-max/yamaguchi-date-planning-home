## Codexが次に行う作業

### 優先度1：公開情報の整理

公開ページはGitHub Pagesで公開されているため、以下の情報を公開データから削除または抽象化する。

削除・抽象化する情報：

- 診断名
- 病歴
- 手帳等級
- 家族事情
- 関係性トラブル
- 過去の傷
- 彼女の弱点
- 会話ログ原文
- 深い個人文脈

置き換え表現：

- 移動負担が少ない
- 休憩しやすい
- 静かに話せる
- 短時間でも成立する
- 雨でも行きやすい
- 料金・割引は公式で要確認
- 事前相談しやすい
- 写真で季節感が伝わる

特に確認するファイル：

- `weekly-history-data.js`
- `date-plans-data.js`
- `index.html`
